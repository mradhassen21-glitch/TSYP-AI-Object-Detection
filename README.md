

\# AI-TSYP Object Detection



\## Overview

An AI-based computer vision project using YOLOv8 for object detection and classification.



\## Technologies

\- Python

\- YOLOv8

\- Ultralytics

\- OpenCV

\- NumPy



\## Project Scripts



| File | Description |

|---|---|

| debris\_edge.py | Edge detection |

| detect\_labels.py | Label detection |

| inspect\_data.py | Dataset inspection |

| merge.py | Dataset merging |

| resplit.py | Dataset splitting |

| resume.py | Resume model training |

| train2.py | Model training |



\## Installation



```bash

pip install -r requirements.txt

```



\## Training



```bash

python train2.py

```
